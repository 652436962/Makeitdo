| 项目 | 参数 |
|------|------|
| **SoC** | Rockchip RK3566 |
| **CPU** | 四核 Cortex-A55 @ 1.8GHz, 22nm |
| **GPU** | Mali-G52 2EE, 支持 Vulkan 1.1 / OpenGL ES 3.2 / OpenCL 2.0 |
| **NPU** | 0.8 TOPS @ INT8, 支持主流框架模型转换 |
| **VPU** | 解码: 4K@60 H.265/H.264/VP9; 编码: 1080P@100 H.265 |
| **RAM** | 1/2/4/8 GB LPDDR4/4X |
| **eMMC** | 8/32/64/128 GB (板载) |
| **无线** | WiFi 5 (2.4G/5G) + BT 5.0 (BLE) |
| **以太网** | 10/100/1000M PHY (YT8531C) 板载 |
| **PMU** | Rockchip RK809-5 |
| **尺寸** | 55 × 40 mm |
| **重量** | 12 g |
| **连接器** | 2× 100-pin + 1× 24-pin 高密度 B2B (兼容树莓派 CM4 物理封装) |

### 2.2 IO 资源梳理

从两路 100-pin 连接器 + 24-pin 补充连接器引出的全部可用资源：

| 接口类型 | 数量 | 详情 |
|---------|------|------|
| MIPI DSI | 2路 | DSI0: 4-lane, DSI1: 2-lane (本项目使用 DSI0 驱动主屏) |
| MIPI CSI | 2路 | CSI0: 4-lane, CSI1: 2-lane (预留) |
| HDMI 2.0 | 1路 | 最高 4K@60fps, 支持 HDR |
| eDP | 1路 | 嵌入式 DisplayPort (预留) |
| USB 3.0 | 1路 | 5Gbps SuperSpeed (背部 Type-A) |
| USB 2.0 | 3路 | 其中一路用作 OTG |
| PCIe 2.1 | 1路 | x1 lane, 5GT/s, 与 SATA 复用 |
| SATA 3.0 | 1路 | 与 PCIe 复用 |
| SDMMC | 1路 | SD3.0, 用于 TF 卡槽 |
| I2S / PCM | 多路 | 用于音频 |
| UART | 多路 | 调试和扩展 |
| SPI | 多路 | 扩展外设 |
| I2C | 6路 | 外设通信 |
| GPIO | 大量 | 按键矩阵 / 控制信号 |
| PWM | 多路 | 背光调节 / 风扇调速 |
| ADC | 多路 | 电池电压监测 |
| 以太网 MDI | 1路 | 10/100/1000M (可选引出) |

### 2.3 核心板选型对比与推荐

| 对比维度 | Orange Pi CM4 | 树莓派 CM4 | Radxa CM3 |
|---------|---------------|-----------|-----------|
| **SoC** | RK3566 (4×A55) | BCM2711 (4×A72) | RK3566 (4×A55) |
| **制程** | 22nm | 28nm | 22nm |
| **GPU Vulkan** | 1.1 (G52) | 不支持 | 1.1 (G52) |
| **NPU** | 0.8 TOPS | 无 | 0.8 TOPS |
| **PCIe** | 2.1 x1 | 2.0 x1 | 2.1 x1 |
| **视频编码** | 1080p100 H.265 | 1080p30 H.264 | 1080p100 H.265 |
| **功耗 (空闲)** | ~1.5W | ~2.5W | ~1.5W |
| **整板价格 (4GB+32G)** | ~$34 | ~$45+ | ~$40 |
| **生态成熟度** | 中 (Armbian支持好) | 高 | 中 |

**选型理由**：
- **功耗优势明显**：22nm 制程相比树莓派 CM4 的 28nm 更省电，对手持设备电池续航至关重要
- **GPU 更强**：Mali-G52 支持 Vulkan 1.1，模拟器性能上限更高 (PSP/Dreamcast 级别流畅)
- **视频编码能力强**：支持 1080p@100fps H.265 编码，为串流/录屏提供硬件加速
- **性价比高**：同内存/存储配置下价格约为树莓派 CM4 的 60-75%
- **CM4 兼容封装**：可直接使用树莓派 CM4 生态中的底板设计作为参考

**推荐配置**: Orange Pi CM4 **8GB RAM + 64GB eMMC** 版本，为多任务和大型模拟器 (N64/PSP) 提供充足内存余量。

### 2.4 CM4 接口在手柄场景的分配策略

```
CM4 100-pin 连接器资源分配:

【显示】
  MIPI DSI0 (4-lane)  → 5.5寸 1080p 主屏
  HDMI 2.0            → Mini HDMI 背部输出
  eDP                 → 悬空/预留焊盘

【音频】
  I2S0               → MAX98357A 功放 → 立体声扬声器
  HP_OUT/MIC_IN      → 3.5mm 耳机座 (ALC5686 codec)

【USB】
  USB3.0_0           → USB-A 3.0 背部
  USB2.0_1           → USB-C OTG 背部
  USB2.0_2           → 预留 (内部扩展)

【存储】
  PCIe 2.1 x1        → M.2 M-Key 2280 (NVMe SSD) 背部
  SDMMC0             → TF 卡槽 (系统启动)

【外设通信】
  I2C1               → 触摸屏 + 六轴 IMU (共用总线)
  I2C2               → 霍尔摇杆 ×2 (通过多路复用器)
  I2C0               → 库仑计 MAX17048
  SPI0               → 预留 (可接外部 SPI Flash 或 TFT 副屏)

  GPIO[BOOT/RST]     → ELRS 模块烧录控制

【控制】
  GPIO[0:11]         → 按键矩阵 (4行×8列)
  GPIO[12:15]        → 功能按键直连 (Home/Start/Select/Power)
  PWM1               → 背光亮度控制
  PWM2               → 风扇转速控制
  ADC[1:2]           → 电池电压分压采样
```

## 3. 显示子系统设计

### 3.1 屏幕选型

| 参数 | 规格 |
|------|------|
| **尺寸** | 5.5 英寸 (16:9 宽高比) |
| **分辨率** | 1080 × 1920 (FHD) 竖屏原生 |
| **面板类型** | IPS (全视角) |
| **接口** | MIPI DSI 4-lane |
| **色深** | 24-bit (1670万色) |
| **亮度** | ≥ 400 cd/m² (户外可见) |
| **对比度** | ≥ 1000:1 |
| **触摸** | 电容式多点触控 (GT911 或 FT6336) |

**推荐屏幕型号参考**：
- **兼容屏**: Nintendo Switch Lite 替换屏 (5.5寸 720×1280 可升级到 1080×1920 面板)
- **工业屏方案**: 通过 5.5寸 1080p MIPI DSI 面板供应商定制 (阿里巴巴/淘宝可采购)
- **适配注意**: 屏幕驱动 IC 需支持 MIPI DSI 4-lane 命令模式 (Command Mode) 或 视频模式 (Video Mode)，RK3566 两者均支持

### 3.2 MIPI DSI 接口连接

RK3566 → LCD 面板信号连接：

```
RK3566 DSI0                     LCD Panel
─────────────                   ─────────────
DSI_TX0_D0_P/N  ────────────►  DSI_D0+/-
DSI_TX0_D1_P/N  ────────────►  DSI_D1+/-
DSI_TX0_D2_P/N  ────────────►  DSI_D2+/-
DSI_TX0_D3_P/N  ────────────►  DSI_D3+/-
DSI_TX0_CLK_P/N ────────────►  DSI_CLK+/-
GPIO (PWM)      ────────────►  LCD_BL_PWM (背光PWM)
GPIO (EN)       ────────────►  LCD_RST (复位)
I2C1_SDA        ────────────►  TP_SDA (触摸I2C)
I2C1_SCL        ────────────►  TP_SCL (触摸I2C)
GPIO            ────────────►  TP_INT (触摸中断)
GPIO            ────────────►  TP_RST (触摸复位)
VCC_3V3         ────────────►  VCC/VDD (逻辑电位移至3.3V)
LED+ (Boost)    ◄────────────  LCD背光LED供电 (~18-24V)
```

**PCB 布局要点**：
- MIPI DSI 差分线需等长走线，阻抗控制 100Ω 差分
- FPC 连接器建议用 40-pin 0.5mm 间距翻盖式 ZIF
- 背光驱动电路与数字信号区域保持距离，减少干扰

### 3.3 触摸屏方案

选用 **Goodix GT911** 或 **FocalTech FT6336** 电容触控 IC：

| 参数 | GT911 | FT6336 |
|------|-------|--------|
| 触控点数 | 5点 | 5点 |
| 接口 | I2C (地址 0x5D/0x14) | I2C (地址 0x38) |
| 供电 | 2.8V - 3.3V | 2.8V - 3.3V |
| 中断方式 | GPIO 下降沿 | GPIO 下降沿 |
| 驱动支持 | Linux mainline 已有驱动 | Linux mainline 已有驱动 |

### 3.4 背光驱动

- 推荐 **TPS61165** 或 **MP3302** 白光 LED 升压驱动 IC
- 输入: 3.3V 或 5V，输出升压至 ~18-24V 恒流驱动 LED 串
- PWM 调光频率 ≥ 20kHz 避免人耳可听噪声
- 最大亮度时效率 > 85%

## 4. 音频子系统设计

### 4.1 整体方案

```
┌──────────┐     ┌──────────────┐     ┌─────────────┐
│  RK3566  │ I2S │  MAX98357A   │ PWM │ 立体声扬声器  │
│  I2S0    │────►│  (D类功放×2)  │────►│  2× 2W/4Ω   │
└──────────┘     └──────────────┘     └─────────────┘
       │
       │ I2S + GPIO
       ▼
┌──────────────┐     ┌──────────┐     ┌─────────────┐
│  ALC5686 /   │────►│ 3.5mm座  │────►│  耳机输出    │
│  WM8960      │     │ (带检测) │     │  + MIC输入   │
│  Audio Codec │◄────│          │◄────│  (驻极体MIC) │
└──────────────┘     └──────────┘     └─────────────┘
```

### 4.2 扬声器方案

| 组件 | 选型 | 说明 |
|------|------|------|
| 功放芯片 | **MAX98357A** ×2 | I2S 输入, D类, 3.2W/4Ω, PDM输出可选 |
| 扬声器单元 | 13×18mm 椭圆形, 4Ω 2W ×2 | 类似 Switch 尺寸 |
| 音频腔体 | 后腔 ≥ 1cc, 出声孔面积 ≥ 10mm² | 保证低频响应 |

MAX98357A 的 I2S 连接：
```
RK3566 I2S0             MAX98357A
─────────────           ─────────────
I2S0_MCLK   ────────►   MCLK
I2S0_BCLK   ────────►   BCLK
I2S0_LRCK   ────────►   LRCLK
I2S0_SDO0   ────────►   DIN (左声道)
I2S0_SDO1   ────────►   DIN (右声道, 第2颗)
GPIO        ────────►   SD_MODE (左右声道选择)
GPIO        ────────►   GAIN  (增益设置)
```

### 4.3 耳机与麦克风

- **Codec 芯片**: 推荐 **WM8960** (I2S + I2C 控制) 或直接使用 RK809-5 自带的音频通路
- **3.5mm 插座**: PJ-320A 型 5-pin (L/R/GND/MIC/DET)
- **插入检测**: GPIO 读取 DET pin 高低电平，自动切换扬声器/耳机输出
- **MIC**: 驻极体麦克风 (ECM), 偏置电压 2V

### 4.4 音量控制

采用**数字音量控制**方案：通过 ALSA (Advanced Linux Sound Architecture) mixer 控制 MAX98357A 和 Codec 的内部数字音量寄存器。无需外接电位器，减少体积和成本。另外预留两个 GPIO 用于物理音量 ± 按键。

### 5.2 霍尔效应摇杆 ×2

| 参数 | 规格 |
|------|------|
| 传感器类型 | 霍尔效应 (非接触式) |
| 接口 | I2C (推荐) 或 模拟电压 (ADC) |
| 推荐型号 | **CJHALL-PI043** 或 **KS1113** |
| 供电 | 3.3V |
| 分辨率 | 12-bit ADC (4096 级) |
| 寿命 | ≥ 200万次循环 |
| I2C 地址 | 0x30 (左) / 0x31 (右) 通过地址选择引脚区分 |

**为什么选霍尔摇杆而非电位器摇杆？**
- 无物理接触，无磨损，寿命远超碳膜电位器摇杆
- 无漂移问题 (Switch 最大痛点)
- 精度更高，线性度更好

### 5.3 按键矩阵设计

使用 **4行 × 8列** 矩阵扫描，最多支持 32 个按键：

```
           COL0   COL1   COL2   COL3   COL4   COL5   COL6   COL7
           GPIO0  GPIO1  GPIO2  GPIO3  GPIO4  GPIO5  GPIO6  GPIO7
ROW0 GPIO8   A      B      X      Y     UP    DOWN   LEFT  RIGHT
ROW1 GPIO9   L      R     LZ     RZ     —      —      —      —
ROW2 GPIO10 Sel  Start   Home  Turbo   —      —      —      —
ROW3 GPIO11  —      —      —      —      —      —      —      —
```

按键连接示意 (以 A 键为例)：
```
ROW0 (GPIO8) ─────┬───── 按键 A ───── COL0 (GPIO0)
                   └───────┤  ├──────────────┘
```

**扫描方式**：
- 逐行拉低 ROW，读取 COL 状态
- 扫描频率 ≥ 100Hz (10ms 去抖动)
- 可通过 Linux `gpio-keys` 驱动或 `evdev` 上报

**肩键 (独立 GPIO)**：
- L / R / LZ / RZ 使用独立 GPIO 直连以降低延迟
- 按键类型：轻触开关 (ALPS SKHLLC / Omron B3F)

### 5.4 六轴 IMU (陀螺仪 + 加速度计)

| 参数 | 规格 |
|------|------|
| 推荐型号 | **ICM-42688-P** 或 **BMI270** |
| 接口 | I2C (与触摸屏共用总线 I2C1) |
| I2C 地址 | 0x68 (ICM-42688-P) |

| 加速度计范围 | ±16g |
| 驱动支持 | Linux IIO 子系统已有驱动 |

**用途**：
- 体感瞄准 (在支持陀螺仪的模拟器中)

- 下坠检测

### 5.5 双马达振动反馈 (可选)

| 组件 | 选型 | 说明 |
|------|------|------|
| 振动马达 | **线性谐振马达 (LRA)** ×2 | 类似 Switch HD Rumble |

## 7. ELRS 射频控制子系统

ExpressLRS (ELRS) 是目前 FPV 穿越机、无人机、无人车和机器人领域最流行的开源射频遥控链路。本掌机将内置 ELRS 发射模组，摇杆和按键可直连遥控通道，让掌机变身为功能强大的无人机/无人车遥控器。

### 7.1 系统架构

```
┌───────────────────────────────────────────────────────────────────┐
│                        掌机内部                                    │
│                                                                   │
│  ┌──────────┐    UART1 (CRSF)     ┌─────────────────────────┐    │
│  │  RK3566  │◄──────────────────►│   ELRS 发射模组 (PCB)    │    │
│  │  CM4     │   TX/RX/CTS/RTS    │                         │    │
│  │          │                    │  ┌─────────┐ ┌───────┐  │    │
│  │ 摇杆→通道│    GPIO (BOOT/RST)  │  │ESP32-C3 │ │SX1280 │  │    │
│  │ 按键→开关│◄──────────────────►│  │ 主控MCU │ │RF前端 │  │    │
│  │ 遥测显示│                    │  │WiFi/BLE │ │2.4GHz │  │    │
│  └──────────┘                    │  └─────────┘ └───┬───┘  │    │
│                                  │                  │      │    │
│                                  │            IPEX/U.FL     │    │
│                                  └──────────────────┬──────┘    │
│                                                     │           │
│                                            SMA 天线座 (背部)     │
│                                                     │           │
└─────────────────────────────────────────────────────┼───────────┘
                                                      │
                                                      ▼
                                              ┌──────────────┐
                                              │  2.4GHz 天线  │
                                              │  (可折叠/可拆) │
                                              └──────────────┘
```

### 7.2 模组选型

#### 方案 A：PCB 板载集成 (推荐)

将 ELRS 核心电路直接设计在底板上，高度集成，节省空间。

| 组件 | 型号 | 说明 |
|------|------|------|
| **主控 MCU** | ESP32-C3-MINI-1 或 ESP32-S3-MINI-1 | RISC-V 或 Xtensa 核心, 板载天线 + IPEX |
| **射频前端** | SX1280IMLTRT | Semtech 2.4GHz 收发器, 与 ELRS 原生兼容 |
| **PA/LNA** | SE2431L (可选) | 功率放大器 + 低噪声放大器, 提升至 250mW/500mW |
| **TCXO** | 26MHz ±0.5ppm | 温补晶振, 保证频率稳定 |
| **RF 开关** | SKY13351 | SPDT 收发切换 (仅带 PA 时使用) |
| **天线座** | SMA-KE 偏脚 或 IPEX MHF4 | 背部引出, 可接各种 2.4GHz 天线 |

**ELRS 核心电路与 CM4 的接口**：

```
RK3566 CM4                         ELRS 模组 (ESP32-C3 + SX1280)
──────────                         ──────────────────────────────
UART1_TX   ─────────────────►  ESP_RX  (CRSF 串行数据, 摇杆/通道值)
UART1_RX   ◄─────────────────  ESP_TX  (遥测回传, RSSI/LQ/电压等)
GPIO  (BOOT) ───────────────►  ESP_IO0 (固件烧录引导, 低电平触发)
GPIO  (RST)  ───────────────►  ESP_EN  (模块复位, 低电平复位)
VCC_3V3     ─────────────────►  VCC     (3.3V 供电, 峰值 ~350mA)
GND         ─────────────────►  GND
```

#### 方案 B：外部 JR 标准模组仓 (备选)

在背部预留标准 5-pin JR 模组仓接口，兼容市面上所有 JR 规格 ELRS 模组 (如 HappyModel ES24TX-Pro, BetaFPV Nano 等)。

| 引脚 (上→下) | JR 标准信号 | 本项目连接 |
|-------------|-----------|----------|
| 1 | PPM (CPPM) | 悬空 (ELRS 不使用 PPM) |
| 2 | HEARTBEAT | 悬空或 GPIO (供电使能) |
| 3 | VMAIN (VBAT) | 电池电压 6.0-8.4V (直连电池) |
| 4 | GND | GND |
| 5 | S.PORT (UART TX) | UART1_TX (CRSF 协议) |

> **推荐方案 A**：板载集成更紧凑, 无需额外购买模组, BOM 成本仅 $8-10。方案 B 作为兼容性备选, 40-pin GPIO 排针处已预留 UART 资源。

### 7.3 射频性能

| 参数 | SX1280 (无 PA) | SX1280 + SE2431L (带 PA) |
|------|---------------|-------------------------|
| **频率范围** | 2400 - 2480 MHz | 同 |
| **最大发射功率** | 12.5 dBm (~18 mW) | 24 dBm (~250 mW) |
| **接收灵敏度** | -132 dBm @ 50kbps | -135 dBm @ 50kbps |
| **数据速率 (LoRa)** | 50 - 2000 kbps | 同 |
| **ELRS 包率** | 25 - 1000 Hz | 同 |
| **理论距离 (250mW)** | — | ≥ 10km (LOS, 50Hz) |
| **实测距离 (典型)** | ~500m (无 PA) | 3-8km (带 PA, 空旷) |

> **建议**：带 PA/LNA 的版本更适合无人机/无人车远距离操控场景。但对机器人/近距离场景，无 PA 版本功耗更低，散热更好。

### 7.4 天线设计

- **连接器**：IPEX MHF4 (板端) → SMA-KE (外壳端)
- **天线类型**：
  - 可折叠棒状天线 (2dBi, 收纳方便, 类似 FPV 遥控器)
  - 或 固定式短棒天线 (1.5dBi)
- **天线位置**：背部上方 (北部扩展 IO 区域), 远离 CM4 板载 WiFi 天线以减少同频干扰
- **阻抗匹配**：50Ω 微带线, 需要 π 型匹配网络预留位

### 7.5 供电与功耗

| 运行模式 | 功耗 (无 PA) | 功耗 (带 PA, 250mW) |
|---------|------------|-------------------|
| **待机 (无发射)** | ~80 mA @ 3.3V (0.26W) | ~120 mA @ 3.3V (0.40W) |
| **10mW 发射** | ~120 mA @ 3.3V (0.40W) | ~180 mA @ 3.3V (0.59W) |
| **100mW 发射** | ~200 mA @ 3.3V (0.66W) | ~350 mA @ 3.3V (1.16W) |
| **250mW 发射** | N/A | ~500 mA @ 3.3V (1.65W) |

> 3.3V 供电需能稳定提供 ≥ 600mA (带 PA 时), 建议从系统 5V 轨经独立 LDO (如 AMS1117-3.3, 1A) 降压供给。

### 7.6 控制映射 (摇杆/按键 → ELRS 通道)

| 物理输入 | CRSF 通道 | 典型用途 |
|---------|----------|---------|
| 左摇杆 Y (上下) | CH1 | 油门 (Throttle) |
| 左摇杆 X (左右) | CH2 | 偏航 (Yaw) |
| 右摇杆 Y (上下) | CH3 | 俯仰 (Pitch) |
| 右摇杆 X (左右) | CH4 | 横滚 (Roll) |
| L 肩键 | CH5 (ARM) | 解锁/锁定电机 (2段开关) |
| R 肩键 | CH6 | 飞行模式切换 / 蜂鸣器 |
| LZ 肩键 | CH7 | 辅助开关 1 (如 Turtle Mode) |
| RZ 肩键 | CH8 | 辅助开关 2 (如 GPS Rescue) |
| 十字键 上/下 | CH9 (旋钮) | 图传功率 / OSD 参数调节 |
| A 键 | CH10 | 预置功能 (Acknowledge) |
| B 键 | CH11 | 预置功能 |

> 通道映射可以通过 ELRS Configurator 或 EdgeTX/OpenTX 脚本在系统运行时实时配置。

### 7.7 固件与配置

**ELRS 固件构建**：
- 使用 ExpressLRS Configurator (桌面版或 Web 版)
- 目标平台选择 `DIY_2400_TX_ESP32_SX1280_E28` (适用于 ESP32 + SX1280 方案)
- 通过 CM4 的 USB-C OTG 或 UART 进入 ESP32 烧录模式 (拉低 IO0 后复位)

**WiFi 配置模式**：
- 上电时 ESP32 默认进入 WiFi AP 模式 (SSID: `ExpressLRS TX`)
- 手机/PC 连接后通过浏览器访问 `http://10.0.0.1` 即可配置

**摇杆数据注入**：
- CM4 端运行一个 CRSF 数据注入程序, 从 `/dev/input/` 读取摇杆和按键事件
- 按 CRSF 帧格式封装为 26 字节 RC Channels Packed 帧
- 通过 `/dev/ttyS1` (UART1) 以 921600 bps 发送给 ELRS 模组
- 参考实现: [Arduino-Transmitter-for-ELRS](https://github.com/kkbin505/Arduino-Transmitter-for-ELRS)

### 7.8 安全注意事项

- **ARM 通道锁**：默认上电时 CH5 (ARM) 必须处于低位 (解锁需主动切换到高位), 防止意外启动
- **射频暴露**：250mW 模式下天线与人体的距离需 ≥ 20cm
- **频率合规**：使用 ELRS 前确认所在国家/地区的 2.4GHz 频段法规
- **散热**：250mW 持续发射时 SX1280 + PA 会明显发热 (~50°C), 需依赖系统散热风道

```
┌──────────┐     ┌─────────┐     ┌──────────┐
│电源按键   │────►│ 软开机  │────►│  RK809-5 │────► 系统启动
│(Power)   │     │ RC延迟  │     │  PMIC    │
└──────────┘     └─────────┘     └──────────┘
                                         │
                    ┌─────────────────────┘
                    ▼
              ┌──────────┐
              │ 长按6秒  │────► 强制关机
              └──────────┘
```

- **开机**：短按 Power 键 → RK809-5 上电 → SoC 启动
- **休眠**：系统进入 suspend-to-RAM (STR)，功耗 < 50mW
- **唤醒**：短按 Power 键或任意按键唤醒
- **强制关机**：长按 Power 键 ≥ 6秒

| **成本** | 中 (~$50) | 低 (~$30) | 高 (~$200+) |
| **频段** | **4G LTE** | 5.8GHz | 5.8GHz |
| **需要** | **SIM卡+流量** | 直视范围 | 直视范围 |

| **劣势** | 有延迟 | 距离受限 | 距离受限 |

**推荐方案**：4G OpenIPC 为主 (远程)，5.8GHz 为备用 (低延迟竞速)。

### 8.4 Joy-Con 式可拆卸手柄分析

**可行性**：低。主要制约因素：

1. **连接器复杂度**: Switch Joy-Con 使用专门设计的滑轨连接器 (Rail Connector)，包含多路数据、供电和结构卡扣，定制成本极高
2. **蓝牙通信**: 如果做成无线可拆卸手柄，需要独立的 MCU + 电池 + 蓝牙模块，每只手柄成本增加 $15-20
3. **结构强度**: 3D 打印外壳难以保证滑轨的精度和耐磨性

**推荐方案**：**一体式机身**，手柄不可拆卸。如确需分体，可考虑：
- 外接蓝牙手柄 (PS/Xbox 布局)
- 或者后期迭代升级为有线 USB-C 可拆卸模块

| **Armbian** | 通用 Linux 桌面 / 自行搭建 | 6.1 LTS+ | 对 RK3566 支持最好，社区活跃 |
| **Batocera.Linux** | 纯游戏模拟器 | 定制内核 | 开箱即用的游戏前端，支持 100+ 平台 |
| **JELOS** | 纯游戏模拟器 | 6.x+ | Batocera 的轻量替代，界面更现代 |
| **Recalbox** | 纯游戏模拟器 | 定制内核 | 兼容性好，配置简单 |

**本项目推荐**：
1. **主力系统**: Batocera.Linux — 专为模拟器掌机优化的系统，集成 RetroArch + EmulationStation
2. **辅助系统**: Armbian — 作为桌面 Linux 使用，兼顾轻办公/开发
3. **双系统启动**: 通过 TF 卡 (Batocera) + eMMC (Armbian) 实现双系统切换

### 9.2 模拟器性能预估 (RK3566)

| 平台 | 性能 | 备注 |
|------|------|------|
| FC / SFC / MD / GBA | 满帧 (100%) | 轻松运行 |

```dts
// 示例：MIPI DSI 屏幕
&dsi0 {
    status = "okay";

        compatible = "panel-simple-dsi";
        reg = <0>;
        reset-gpios = <&gpio3 RK_PC1 GPIO_ACTIVE_LOW>;
        backlight = <&backlight>;
        // 1080×1920 时序参数...
    };
};

// I2S 音频
&i2s0_8ch {
    status = "okay";
};

// 按键矩阵
&gpio_keys {
    status = "okay";
    button-a { gpios = <&gpio3 RK_PA0 GPIO_ACTIVE_LOW>; };
    // ...

// SPI / I2C / UART ...
```

### 9.4 构建与烧录

**推荐开发流程**：

1. 在 PC 上用交叉编译工具链编译 Armbian 内核和设备树
2. 通过 USB-C OTG 进入 MaskROM 模式烧录 U-Boot
3. 制作 TF 卡镜像，包含完整 Linux 文件系统
4. 通过 SSH 连接进行驱动调试
5. 最终整合 Batocera 或 Armbian 镜像，发布社区版本

## 11. 应用场景与使用指南

本掌机不仅是游戏设备，更是一个多功能的 Linux 遥控平台。内置 ELRS 射频模组使其可直接控制无人机、无人车、机器人等设备。

### 11.1 无人机遥控 (FPV 穿越机)

```
┌─────────────┐      ELRS 2.4GHz      ┌─────────────┐
│   掌机      │ ◄──────────────────► │  无人机     │
│  (发射端)   │    CRSF 协议          │  (接收端)   │
│             │    50-1000Hz          │             │
│  摇杆→通道  │    ≤1ms 延迟          │  ELRS 接收机│
│  遥测显示   │                       │  → 飞控    │
└─────────────┘                       └─────────────┘
```

**典型配置**：
- **通道映射**：左摇杆 Y=油门, X=偏航; 右摇杆 Y=俯仰, X=横滚
- **解锁控制**：L 肩键 = ARM (解锁/锁定电机)
- **飞行模式**：R 肩键 = 模式切换 (Acro/Horizon/Angle)
- **辅助功能**：LZ/RZ = Turtle Mode / GPS Rescue
- **图传调节**：十字键 = 图传功率 / OSD 参数

**推荐搭配飞控**：
- Betaflight / INAV / ArduPilot 固件
- ELRS 接收机 (如 BetaFPV ELRS 2.4G, HappyModel EP系列)
- 5.8GHz 图传 + FPV 眼镜 (可选)

### 11.2 无人车遥控 (地面车辆)

**应用场景**：
- 遥控车 (RC Car) 竞速/攀爬
- 无人巡检车
- 自动驾驶开发平台

**通道映射示例**：

| 通道 | 物理输入 | 用途 |
|------|---------|------|
| CH1 | 左摇杆 X | 转向 (Steering) |
| CH2 | 左摇杆 Y | 油门 (Throttle) |
| CH3 | 右摇杆 Y | 刹车 (Brake) |
| CH4 | 右摇杆 X | 辅助通道 |
| CH5 | L 肩键 | 解锁/锁定 |
| CH6 | R 肩键 | 灯光/喇叭 |

**推荐搭配**：
- ESP32/STM32 主控 + ELRS 接收机
- PCA9685 舵机驱动板
- 电机驱动 (L298N / TB6612)

### 11.3 机器人遥控

**应用场景**：
- 机械臂控制
- 轮式/履带式机器人
- 四足机器人 (Spot 类)

**高级控制模式**：
- **手动模式**：直接控制关节/运动
- **半自主模式**：掌机发送高层指令，机器人自主执行
- **编程模式**：通过 WiFi 连接，使用 Python/C++ 编程控制

**机械臂通道映射示例**：

| 通道 | 物理输入 | 机械臂关节 |
|------|---------|-----------|
| CH1 | 左摇杆 X | 底座旋转 (Base) |
| CH2 | 左摇杆 Y | 肩部 (Shoulder) |
| CH3 | 右摇杆 Y | 肘部 (Elbow) |
| CH4 | 右摇杆 X | 腕部旋转 (Wrist) |
| CH5 | L 肩键 | 夹爪开合 (Gripper) |
| CH6 | R 肩键 | 模式切换 |

### 11.4 多设备切换

掌机支持通过 ELRS 配对存储多个接收机，可快速切换控制不同设备：

```
┌─────────────┐
│   掌机      │
│             │
│  配对列表:  │
│  1. 穿越机A │ ← 当前连接
│  2. 无人车B │
│  3. 机械臂C │
│  ...        │
└─────────────┘
```

**切换方式**：
- ELRS WiFi 配置页面切换
- 或通过 OSD 菜单 (如连接 FPV 眼镜时)

### 11.5 遥测数据回传

ELRS 支持双向遥测，掌机可实时显示：

| 遥测参数 | 来源 | 显示方式 |
|---------|------|---------|
| RSSI (信号强度) | ELRS 协议 | 屏幕/OSD |
| LQ (链路质量) | ELRS 协议 | 屏幕/OSD |
| 电池电压 | 飞控/车载电调 | 屏幕/OSD |
| GPS 坐标 | GPS 模块 | 屏幕/OSD |
| 高度/速度 | 气压计/GPS | 屏幕/OSD |
| 温度 | 传感器 | 屏幕/OSD |

### 11.6 扩展能力

**背部接口扩展**：
- **USB-A 3.0**：外接 USB 游戏手柄、键鼠、U盘
- **USB-C OTG**：连接 PC 进行 ADB 调试、固件烧录
- **40-pin GPIO**：连接外部传感器、执行器、自定义硬件
- **M.2 NVMe**：大容量存储 (游戏 ROM、机器人地图数据等)

**软件扩展**：
- **Python/Node-RED**：可视化编程控制机器人
- **ROS 2**：机器人操作系统集成
- **MQTT**：物联网设备联动
- **Web 控制面板**：通过浏览器远程监控
