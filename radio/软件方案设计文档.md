### 1.2 数据流概览

```
用户输入数据流:
  摇杆(I2C)/按键(GPIO) → Linux evdev → SDL2/libevdev → 模拟器/游戏
  触摸屏(I2C)          → Linux evdev → libinput/Wayland → 桌面/GUI

图形渲染数据流:
  模拟器/游戏 → SDL2/Vulkan → Mesa (Panfrost) → DRM/KMS → MIPI DSI → LCD
  桌面/GUI     → Wayland → Mesa → DRM/KMS → MIPI DSI → LCD

ELRS 遥控数据流:
  摇杆/按键 → evdev → elrs-qt (UART1) → ESP32 → SX1280 RF → 无人机

4G 图传数据流:
  4G 模组 → ModemManager/wwan → GStreamer RTSP → H.264 硬解码 → Wayland → LCD

音频数据流:
  模拟器/游戏 → SDL2 Audio → ALSA/PipeWire → I2S0 → MAX98357A → 扬声器
                                                      → Codec → 耳机
```

## 3. Linux 内核与设备树

### 3.1 内核版本与补丁

| 项目 | 详情 |
|------|------|
| **主线版本** | Linux 6.1 LTS (Rockchip 官方 BSP) |
| **补丁来源** | Rockchip SDK (https://github.com/rockchip-linux/kernel) |
| **目标配置** | `rk3566-makeitdo_defconfig` |
| **设备树** | `rk3566-makeitdo.dts` ↔ `rk3566-makeitdo.dtb` |
| **内核模块** | Panfrost (GPU), 内置 MIPI DSI / I2S / USB3 / PCIe |

### 3.2 关键内核驱动

| 驱动 | 内核配置 | 用途 |
|------|---------|------|
| **Panfrost** | `CONFIG_DRM_PANFROST=m` | Mali-G52 GPU 开源驱动 |
| **DRM/KMS** | `CONFIG_DRM_ROCKCHIP=y` | 显示框架 + RK 硬件图层合成 |
| **dw-mipi-dsi** | `CONFIG_DRM_DW_MIPI_DSI=y` | MIPI DSI 控制器驱动 |
| **panel-simple** | `CONFIG_DRM_PANEL_SIMPLE=y` | LCD 面板时序配置 |
| **ASoC (I2S)** | `CONFIG_SND_SOC_ROCKCHIP_I2S=y` | I2S 音频接口 |
| **max98357a** | `CONFIG_SND_SOC_MAX98357A=m` | D类功放驱动 |
| **dwc3 (USB3)** | `CONFIG_USB_DWC3=y` | USB 3.0 控制器 |
| **pcie-rockchip** | `CONFIG_PCIE_ROCKCHIP=y` | PCIe 2.1 控制器 (NVMe) |
| **sdhci-of-dwcmshc** | `CONFIG_MMC_SDHCI_OF_DWCMSHC=y` | eMMC/SDIO 控制器 |
| **gpio-keys** | `CONFIG_KEYBOARD_GPIO=y` | GPIO 按键 |
| **matrix-keypad** | `CONFIG_KEYBOARD_MATRIX_MARVELL=y` | 按键矩阵 |
| **goodix** | `CONFIG_TOUCHSCREEN_GOODIX=m` | GT911 触摸屏 |
| **inv-icm42600** | `CONFIG_IIO_ST_ACCEL_3AXIS=m` + IIO | ICM-42688-P 六轴 IMU |
| **max17048** | `CONFIG_BATTERY_MAX17040=m` | 库仑计电量监测 |
| **mp2665** | `CONFIG_CHARGER_MP2665=m` | 充电管理 |
| **rockchip-thermal** | `CONFIG_ROCKCHIP_THERMAL=y` | SoC 温度监测 |
| **pwm-fan** | `CONFIG_SENSORS_PWM_FAN=m` | PWM 风扇控制 |
| **pwm-backlight** | `CONFIG_BACKLIGHT_PWM=y` | 屏幕背光 PWM |
| **mcp251xfd** | — (SPI CAN 预留) | 可选 CAN 总线 |
| **cp210x/ch341** | `CONFIG_USB_SERIAL_CP210X=m` | USB转串口 (调试用) |

### 3.4 模块识别与 DT 自动加载

SODIMM 金手指上的 `MODULE_ID[2:0]` 电平编码在 U-Boot 阶段被 ADC 读取，自动选择对应的设备树：

```
U-Boot 启动流程:
  1. 上电 → SPL 加载 (板载 eMMC)
  2. SPL 初始化 DRAM 并加载 U-Boot proper
  3. U-Boot 读取 ADC MODULE_ID[2:0]
  4. 根据编码选择对应 .dtb 文件
  5. 加载内核 + dtb → Linux 启动

U-Boot 环境变量:
  boot_cmd=run boot_cm4
  boot_cm4=load mmc 0:1 ${fdt_addr_r} rk3566-makeitdo.dtb; booti ${kernel_addr_r} - ${fdt_addr_r}
  boot_cm5=load mmc 0:1 ${fdt_addr_r} rk3588s-makeitdo.dtb; booti ${kernel_addr_r} - ${fdt_addr_r}
```

### 4.2 显示服务器对比

| | X11 (Xorg) | Wayland (Wayfire) | KMS/DRM (无服务器) |

| **窗口管理** | 成熟 | 轻量 | 无需 |
| **推荐场景** | 桌面模式 | **游戏模式 ✅** | 全屏游戏 |

**推荐策略**：双模式切换。

### 4.4 屏幕旋转

5.5" LCD 面板物理为竖屏 (1080×1920)，掌机需要横屏显示 (1920×1080)。旋转在多个层面实现：

| 层面 | 方法 | 性能 | 适用 |
|------|------|------|------|
| **硬件** | MIPI DSI 面板控制器旋转 | 零开销 | ❌ 多数面板不支持 |
| **显示控制器** | RK3566 VOP 旋转 | 零开销 ✅ | 内核 DRM 支持 `reflect_y` + `rotate_90` |
| **DRM/KMS** | `panel.rotation=90` 属性 | 极低 | 推荐 ✅ |
| **应用层** | SDL2 / Vulkan 内部旋转 | 软件开销 | 不推荐 |

**推荐**：内核 DRM 层通过 VOP 硬件旋转，对应用完全透明，零性能损失。

### 5.3 霍尔摇杆校准

霍尔传感器虽然有出厂校准数据，但组装后由于焊接公差和磁铁位置偏移，会产生偏移误差。系统集成 **在线校准** 和 **自动校准** 功能：

```python
# /opt/makeitdo/calibration/joystick-calibrate.py

def auto_calibrate(device_path):
    """
    读取摇杆一段时间的原始数据，计算中心点偏移和有效范围。
    用户需在不触碰摇杆时触发 (开机自动运行 + 手动触发)。
    """
    samples = []
    for t in range(200):  # 采集 2 秒 (200 样本 @ 100Hz)
        x, y = read_joystick_raw(device_path)
        samples.append((x, y))
        time.sleep(0.01)

    center_x = np.median([s[0] for s in samples])
    center_y = np.median([s[1] for s in samples])

    # 存储校准参数
    cal = {"center_x": center_x, "center_y": center_y,
           "range_x": 2048, "range_y": 2048}
    with open(f"/etc/makeitdo/cal-{basename}.json", "w") as f:
        json.dump(cal, f)

    return cal
```

校准文件 `~/.config/makeitdo/joystick-cal.json` 在 gamepadd 启动时读取，对原始值做中心修正。

### 5.5 IMU 体感瞄准

ICM-42688-P 六轴 IMU 通过 Linux IIO 子系统暴露为 `/dev/iio:device0`。体感瞄准数据通过用户空间守护进程转换为手柄的右摇杆偏移输入：

```
IMU 物理 → IIO 内核驱动 → iio-sensor-proxy → motiond → 虚拟摇杆 (uinput)
```

`/opt/makeitdo/motiond` 工作流程:

```
1. 从 iio-sensor-proxy 获取陀螺仪角速度 (rad/s)
2. 高斯滤波 + 低通滤波 (截止频率 15Hz)
3. 转换为右摇杆偏移量 (ABS_RX/ABS_RY)
4. 仅在"体感激活键"被按下时注入偏移 (通常是 L 或 LZ 键)
5. 注入 uinput 虚拟手柄
```

体感配置:

```toml
[motion]
enable = true
activate_button = "BTN_TL"       # L 键激活体感
dead_angle = 0.5                  # 0.5°/s 死区 (静止不漂)
sensitivity = 1.2                 # 灵敏度倍率
filter_type = "lowpass"
filter_cutoff = 15.0              # Hz
```

### 7.2 游戏前端

#### 方案 A：EmulationStation (经典)

```
优点:
  ├── 社区成熟，主题丰富
  ├── 支持 RetroArch 和独立模拟器
  ├── 支持游戏视频预览 / 截图 / 元数据
```

```
  ├── 对内存要求较高 (~200MB)
```

### 8.2 CRSF 协议帧格式

ELRS 使用 CRSF (Crossfire) 串行协议。elrs-qt 负责从 evdev 事件构建 CRSF 帧：

```
CRSF 帧类型及 elrs-qt 处理:

┌─────────────────────────────────────────────────────────────────┐
│ 帧类型                  │ 方向       │ elrs-qt 处理              │
├─────────────────────────────────────────────────────────────────┤
│ 0x16 RC Channels Packed │ CM4 → ELRS │ 核心: 摇杆/按键 → 通道   │
│ 0x14 Link Statistics    │ ELRS → CM4 │ RSSI/LQ/SNR → 显示       │
│ 0x02 GPS                │ ELRS → CM4 │ GPS坐标 → 地图叠加       │
│ 0x1E Attitude           │ ELRS → CM4 │ 飞行姿态 → OSD显示       │
│ 0x08 Battery Sensor     │ ELRS → CM4 │ 电池电压 → 警告          │
│ 0x1B Flight Mode        │ ELRS → CM4 │ 飞行模式 → 状态栏        │
│ 0x1C Device Info        │ ELRS → CM4 │ 设备信息 → 诊断          │
│ 0x29 Msp Write          │ 双向       │ Betaflight MSP 透传      │
└─────────────────────────────────────────────────────────────────┘
```

**RC Channels Packed 帧** (26 字节, 16 通道 11-bit 值)：

```c
// 结构体定义 (elrs-qt 内部)
typedef struct __attribute__((packed)) {
    uint8_t sync;              // 0xC8 (CRSF 地址)
    uint8_t len;               // 24 (有效载荷长度)
    uint8_t type;              // 0x16 (RC Channels Packed)
    uint8_t payload[22];       // 16 个 11-bit 通道值 (位打包)
    uint8_t crc8;              // CRC-8-DVB S2 校验
} crsf_rc_channels_packed_t;
```

```cpp
// src/crsfprotocol.cpp — CRSF 帧构建/解析 (粘包状态机)
QByteArray CrsfProtocol::buildRcFrame(const quint16 channels[16]) {
    QByteArray frame;
    frame.append(char(0xC8));      // CRSF 地址
    frame.append(char(22 + 2));    // 长度 = payload + type + crc
    frame.append(char(0x16));      // RC Channels Packed
    quint32 buf = 0;
    int bits = 0;
    for (int i = 0; i < 16; ++i) { // 16 × 11-bit 大端位打包
        buf = (buf << 11) | (channels[i] & 0x7FF);
        bits += 11;
        while (bits >= 8) {
            frame.append(char((buf >> (bits - 8)) & 0xFF));
            bits -= 8;
        }
    }
    if (bits > 0)
        frame.append(char((buf << (8 - bits)) & 0xFF));
    frame.append(crc8DvbS2(frame.constData() + 2, frame.size() - 3));
    return frame;
}
```

线程模型 — 串口/输入/界面分离，跨线程信号统一 QueuedConnection：

```
主线程   : Qt 事件循环 + 界面, 60Hz 定时器合并刷新通道条/遥测仪表
串口线程 : QSerialPort 读写 /dev/ttyS1, readyRead → 解析 → 信号回主线程
输入线程 : libevdev 阻塞读 /dev/input/js0, 事件投递到通道映射
```

```cpp
EvdevInput::EvdevInput(const QString &devPath, QObject *parent)
    : QObject(parent), m_notifier(nullptr) {
    int fd = open(devPath.toLocal8Bit().constData(), O_RDONLY | O_NONBLOCK);
    libevdev_new_from_fd(fd, &m_dev);
    m_notifier = new QSocketNotifier(fd, QSocketNotifier::Read, this);
    connect(m_notifier, &QSocketNotifier::activated,
            this, &EvdevInput::onEvent);
}

void EvdevInput::onEvent() {
    input_event ev;
    while (libevdev_next_event(m_dev, LIBEVDEV_READ_FLAG_NORMAL, &ev) == 0) {
        if (ev.type == EV_ABS)
            emit axisMoved(ev.code, ev.value);   // 摇杆 → ChannelMap
        else if (ev.type == EV_KEY)
            emit keyChanged(ev.code, ev.value);  // 按键 → ChannelMap
    }
}
```

### 10.4 温控与风扇策略

```bash
# /opt/makeitdo/scripts/fan-control.sh

# 读取 SoC 温度 (rockchip-thermal, IIO)
TEMP=$(cat /sys/class/thermal/thermal_zone0/temp | awk '{print $1/1000}')

# PWM 占空比 = 温度映射函数
if [ $(echo "$TEMP < 45" | bc) -eq 1 ]; then
    DUTY=0        # < 45°C: 风扇停转
elif [ $(echo "$TEMP < 55" | bc) -eq 1 ]; then
    DUTY=30       # 45-55°C: 低速 (安静)
elif [ $(echo "$TEMP < 65" | bc) -eq 1 ]; then
    DUTY=60       # 55-65°C: 中速
elif [ $(echo "$TEMP < 75" | bc) -eq 1 ]; then
    DUTY=85       # 65-75°C: 高速
else
    DUTY=100      # > 75°C: 全速 + 降频
    echo "powersave" | tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
fi

echo $DUTY > /sys/class/pwm/pwmchip0/pwm1/duty_cycle
```

```ini
[Unit]

[Timer]

OnUnitActiveSec=2

[Install]
WantedBy=timers.target
```

### 10.5 电池监测与低电量告警

`/opt/makeitdo/scripts/battery-monitor.sh` (systemd timer, 每 30 秒):

```bash
#!/bin/bash
SOC=$(cat /sys/class/power_supply/max17048-battery/capacity)
STATUS=$(cat /sys/class/power_supply/max17048-battery/status)

# 低电量告警
if [ "$SOC" -le 5 ] && [ "$STATUS" = "Discharging" ]; then
    # 强制休眠
    systemctl suspend
elif [ "$SOC" -le 10 ] && [ "$STATUS" = "Discharging" ]; then
    # 通知用户
    notify-send -u critical "电量低" "剩余 ${SOC}%，请连接充电器"
elif [ "$SOC" -le 20 ] && [ "$STATUS" = "Discharging" ]; then
    # 温和提醒
    notify-send "电量: ${SOC}%" "建议充电"
fi
```

### 11.3 一键备份/恢复

游戏存档/配置备份：

```bash
#!/bin/bash
# /opt/makeitdo/scripts/backup.sh

BACKUP_MOUNT="/mnt/ssd"          # NVMe SSD
BACKUP_DIR="$BACKUP_MOUNT/makeitdo-backups"

case "$1" in
  save|backup)
    TIMESTAMP=$(date +%Y%m%d-%H%M%S)
    BACKUP_FILE="$BACKUP_DIR/savegame-$TIMESTAMP.tar.gz"

    tar -czf "$BACKUP_FILE" \
      -C "$HOME" \
      .config/retroarch/savestates \
      .config/retroarch/saves \
      .local/share/ppsspp/PSP/SAVEDATA \
      .config/makeitdo

    echo "备份完成: $BACKUP_FILE"
    ;;

  restore)
    LATEST=$(ls -t "$BACKUP_DIR"/savegame-*.tar.gz | head -1)
    tar -xzf "$LATEST" -C "$HOME"
    echo "恢复完成: $LATEST"
    ;;

  list)
    ls -lh "$BACKUP_DIR"/savegame-*.tar.gz
    ;;

  *)
    echo "用法: $0 {save|restore|list}"
    ;;
esac
```

### 11.4 OTA 系统更新

使用 RAUC (Robust Auto-Update Controller) 实现 A/B 分区 OTA：

```
存储分区布局 (eMMC / NVMe):

┌─────────────────────────────────────────────────────────┐
│  /dev/mmcblk0                                           │
├─────────┬─────────┬─────────┬─────────┬────────────────┤
│ boot A  │ rootfs A│ boot B  │ rootfs B│  data (共享)    │
│ 256MB   │ 8GB     │ 256MB   │ 8GB     │  剩余空间       │
│ FAT32   │ ext4    │ FAT32   │ ext4    │  ext4/btrfs    │
└─────────┴─────────┴─────────┴─────────┴────────────────┘

更新流程:
  1. 系统运行在 A 分区
  2. 下载更新包到 data 分区
  3. rauc install update.raucb  →  写入 B 分区
  4. 验证 B 分区完整性 (HASH 校验)
  5. 设置 U-Boot 启动 B 分区
  6. 重启 → B 分区启动
  7. 如果启动失败 → 看门狗触发 → 自动回滚到 A
```

RAUC 配置 (`/etc/rauc/system.conf`):

```ini
[system]
compatible=makeitdo-handheld
bootloader=uboot

[slot.boot.0]
device=/dev/mmcblk0p1
type=boot

[slot.rootfs.0]
device=/dev/mmcblk0p2
type=rootfs

[slot.boot.1]
device=/dev/mmcblk0p3
type=boot

[slot.rootfs.1]
device=/dev/mmcblk0p4
type=rootfs
```
