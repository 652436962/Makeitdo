### 1.3 关键尺寸汇总

| 参数 | 数值 | 说明 |
|------|------|------|
| **整机宽度** | 200.0 mm | 包含左右控制区 |
| **整机高度** | 95.0 mm | 含肩键突起 |
| **机身平坦区厚度** | 16.0 mm | 屏幕区域 (含玻璃) |
| **握把区最大厚度** | 20.0 mm | 含弧度 |
| **屏幕有效显示区** | 121.7 × 68.5 mm | 5.5" 16:9 横置 |
| **屏幕外部轮廓** | 133.0 × 76.0 mm | 含黑边/边框 |
| **左控制区宽度** | 39.0 mm | 摇杆 + 十字键 |
| **右控制区宽度** | 39.0 mm | 摇杆 + ABXY |
| **肩键突起高度** | 3.0 mm | 高于机身上沿 |
| **背部 IO 区域** | 70.0 × 25.0 mm | 北部 (上端) |
| **M.2 NVMe 盖板区域** | 80.0 × 26.0 mm | 背部中央 (竖放, 下沉仓) |
| **M.2 ELRS (内部)** | 30.0 × 26.0 mm | 背部左侧 (不开口) |
| **M.2 4G (内部)** | 42.0 × 34.0 mm | 背部右侧 (不开口, 含SIM) |
| **背部按键 M1/M3 (左侧)** | X=25.0, Y=35.0~55.0 mm | 左握把区, 上下排列 |
| **背部按键 M2/M4 (右侧)** | X=175.0, Y=35.0~55.0 mm | 右握把区, 上下排列 |
| **背部按键拨片露出高度** | 1.2 mm | 高于后盖表面 |
| **机身重量 (目标)** | ≤ 430 g | 含电池不含 SSD |

## 3. 外壳分件设计

### 3.1 三分件结构

```
  ┌──────────────────────────────────────────┐
  │          【前面板组件】                      │
  │  · 钢化玻璃面板 (覆盖屏幕区域)               │
  │  · 前面板框架 (按键开口 + 摇杆开口)          │
  │  · 功能按键 (Start/Select/Home) 安装位      │
  │  · 扬声器出声网孔                            │
  └──────────────────────────────────────────┘
                      ↕ 卡扣 + 螺丝固定
  ┌──────────────────────────────────────────┐
  │          【中框组件】                        │
  │  · 主板安装位 (6颗 M2 螺丝柱)              │
  │  · 电池仓 (带泡棉缓冲)                      │
  │  · 散热片固定位                              │
  │  · 左右握持区域 (填充结构 + 防滑纹理)        │
  │  · 风扇固定位 (可选, 2颗 M2)                │
  │  · 肩键转轴安装位 (4组)                     │
  └──────────────────────────────────────────┘
                      ↕ 卡扣 + 螺丝固定
  ┌──────────────────────────────────────────┐
  │          【后盖组件】                        │
│  · M.2 NVMe 下沉仓 (可拆卸盖板, 2颗 M1.6)     │
│  · M.2 ELRS (内部, 开后盖操作)                 │
│  · M.2 4G/5G (内部, 开后盖操作, 含SIM座)       │
│  · 背部扩展 IO 开口 (4个独立开孔)               │
  │  · 散热格栅 (进风/出风百叶窗)               │
  │  · USB-C 充电口开孔 (底部)                  │
  │  · TF 卡槽开孔 (底部)                        │
  │  · 3.5mm 耳机孔开孔 (底部)                   │
  └──────────────────────────────────────────┘
```

## 7. 握持人机工学

### 7.1 握持方式定义

```
  标准双手握持姿势 (参照 Switch):

        左手                         右手
    食指 → L/LZ                    R/RZ ← 食指
    拇指 → 摇杆/十字键          摇杆/ABXY ← 拇指
    中指+无名指 → 握把          握把 ← 中指+无名指
    小指 → 底部支撑             底部支撑 ← 小指
```

### 7.2 握把弧度设计

```
  握把截面 (横向, 从顶部看):

  屏幕区域 (平坦)      握把区域 (弧形, R15)
  ┌──────────────────┐╮
  │                  │ ╲
  │                  │  ╲  R15mm
  │   5.5" LCD       │   ╲
  │                  │    ╲___
  │                  │        ╲
  └──────────────────┘─────────┘
  ◄── 122.0mm ──►◄── 39.0mm ──►
      屏幕区域        握持区域

  握把纵向弧度 (背部隆起的轮廓):
  中心厚度 16mm → 边缘逐渐增加到 20mm
  形成一个贴合掌心的自然隆起
```

### 7.3 表面处理

| 区域 | 材质 | 纹理 | 触感 |
|------|------|------|------|
| 屏幕覆盖 | 钢化玻璃 (9H) | 光滑 + 疏油涂层 | 光滑 |
| 前面板 | PC+ABS (磨砂) | 细磨砂 | 略带阻尼 |
| 握把区 | PC+ABS (纹理) | 菱形防滑纹理 1mm间距 | 防滑, 柔软触感 |
| 后盖 | PC+ABS (磨砂) | 同前面板 | 一致 |
| 按键帽 | PBT 或 ABS | 微磨砂 | 防滑 |
| 摇杆帽 | 硅胶 (可替换) | 同心圆纹理 | 柔软防滑 |

## 8. 公差与制造建议

### 8.1 3D 打印公差

| 参数 | FDM (PLA+) | SLA (光固化) |
|------|-----------|-------------|
| 层高 | 0.12 - 0.20mm | 0.05mm |
| XY 精度 | ±0.2mm | ±0.1mm |
| Z 精度 | ±0.12mm | ±0.05mm |
| 最小壁厚 | 1.2mm | 0.8mm |
| 螺丝孔补偿 | +0.2mm (攻丝余量) | +0.1mm |
| 卡扣间隙 | 0.15mm | 0.10mm |
| 外壳配合间隙 | 0.2mm | 0.15mm |

### 8.2 迭代制造建议

```
  原型阶段 (V0.x):
  · FDM 3D 打印 (PLA+) 快速验证外形和装配
  · 成本低, 迭代快, 1天内可打印一套外壳
  · 卡扣和螺丝孔需反复调试

  验证阶段 (V1.0):
  · SLA 光固化打印 (类ABS树脂) 验证配合精度
  · 表面更光滑, 可直接做表面处理测试
  · 进行实际手持体验评估

  最终阶段 (V2.0+):
  · 如小批量: CNC 铝合金前面板 + 3D 打印中框后盖
  · 如量产: PC+ABS 注塑模具 (需 ≥ 500套 摊薄模具费)
```

### 8.3 PCB 外形与外壳配合

| 参数 | 值 | 说明 |
|------|-----|------|
| PCB 外形尺寸 | 195.0 × 90.0 mm | 略小于外壳内腔 |
| PCB 与外壳间隙 | 0.5mm (每侧) | 装配余量 |
| 螺丝孔直径 | Φ2.2mm | M2 螺丝通过 |
| 螺丝孔距板边 | ≥ 4.0mm | 结构强度 |
| 板边倒角 | R2.0 | 避免锐角卡住外壳 |
| 定位孔 | Φ2.0 ×2 (对角) | 装配定位销 |
