## 1. 电池保护板通讯参数
- 物理接口：**485串口**
- 串口参数：1位起始位、8位数据位、**无校验**、1位停止位、**波特率9600**
- MODBUS装置地址：**固定为1**，单保护板独立485通讯，不使用总线模式
- 仅使用功能码：**01读开关量、03读寄存器**，其余功能码禁用
- 设备ID：寄存器**1000起始**，只读不可修改
- 查询固定步骤：①查设备ID ②查模拟量 ③查开关量
- 应答时序：换电柜下发指令后，BMS应答时间 **2ms～100ms**
- 充电寄存器分区：
  - 41#~43#：常规充电信息
  - 44#~46#：快充充电信息
  - 读取规则：需分两条独立指令读取，**禁止连续读取41-46#**、禁止与模拟量合并读取
- 充满状态规则：电池充满后，读取41#/44#返回电压电流为0，43#/46#为`0x00AA`
- 充电标志位定义：
  - `0x0055`：**允许充电/快充**，按41/42#、44/45#请求值输出
  - `0x00AA`：**禁止充电/快充**，充电器停止输出
  - 其他数值：兼容旧协议，换电柜自主控制充电
- 存量1.0/2.0电池：无主动充电申请字节，43#/46#非AA/55时，换电柜自主控充电

## 3. MODBUS通讯规约
### 3.1 数据传送规则
1. 主从问答式通讯，单帧报文≤255字节
2. 报文正确：500ms内正常响应
3. 地址/校验错误：**无应答**，主站超时重发
4. 地址/校验正确、功能码/数据错误：500ms内异常报文回应
5. 波特率兼容：9600标配，支持1200~57600

### 3.2 数据帧格式
| 装置地址(1字节) | 功能码(1字节) | 数据区(N字节) | CRC校验(2字节) |
| ---- | ---- | ---- | ---- |
| 从机地址 | 读写指令 | 读写地址/长度/数据 | 16位循环冗余校验 |

#### 3.2.1 装置地址
范围0~255，本协议固定**地址1**，从机应答带回自身地址

#### 3.2.2 功能码定义
| 功能码(HEX) | 名称 | 用途 |
| ---- | ---- | ---- |
| 01 | 读开关 | 遥信，读取保护开关状态 |
| 03 | 读寄存器 | 遥测，读取电压/电流/温度等模拟量 |
| 05 | 写单路开关 | 单路遥控分合闸 |
| 06 | 写单个寄存器 | 单寄存器遥调写入 |
| 0F | 写多路开关 | 批量遥控多路开关 |
| 10 | 写多个寄存器 | 批量写入多寄存器 |

#### 3.2.3 异常回应规则
- 错误功能码：原功能码 `| 0x80`（最高位置1）
- 错误编码：
  1=无效报文类型；2=地址/长度越界；3=写入数据无效；6=装置忙

#### 3.2.4 数据区规则
采用**大端模式**，先发高位字节，后发低位字节

### 3.3 功能码详细说明
#### 3.3.1 功能码01 读开关量
- 主机格式：地址+01+起始位地址+开关个数+CRC
- 从机格式：地址+01+数据字节数+开关状态数据+CRC
- 编码规则：1字节存8个开关状态，D0对应起始地址开关

#### 3.3.2 功能码03 读寄存器
- 每个寄存器16位（2字节），支持负数补码
- 主机格式：地址+03+起始寄存器地址+寄存器个数+CRC
- 从机格式：地址+03+数据总字节数+寄存器数据+CRC

#### 3.3.3 功能码05/06/0F/10 写操作
- 05写单路开关：`FF00`合闸、`0000`分闸
- 06写单寄存器、0F写多路开关、10写多寄存器：从机应答与下发报文一致，需回读校验执行结果

### 3.4 CRC16计算
#### 3.4.1 算法步骤
1. CRC寄存器预置 `0xFFFF`
2. 字节与CRC低8位异或
3. 右移1位，移出位为1则异或`0xA001`
4. 单字节循环右移8次，所有字节遍历完成
5. 高低字节交换，输出CRC码

#### 3.4.2 C语言源码
```c
unsigned short ModBusCRC16(const void *s, int n)
{
    unsigned short c = 0xffff;
    for(int k=0; k<n; k++)
    {
        unsigned short b=(((unsigned char *)s)[k]);
        for(char i=0; i<8; i++)
        {
            c = ((b^c)&1) ? (c>>1)^0xA001 : (c>>1);
            b>>=1;
        }
    }
    return (c<<8)|(c>>8);
}
```
