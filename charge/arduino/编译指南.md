# 充电器主控 — Arduino 编译指南

## 环境准备

### 1. 安装 arduino-cli

参考 [arduino-cli 官方文档](https://arduino.github.io/arduino-cli/latest/) 安装。

### 2. 安装 ESP32 核心

```bash
arduino-cli core update-index
arduino-cli core install esp32:esp32
```

### 3. 安装依赖库

```bash
arduino-cli lib install "U8g2"
```

## 编译

```bash
cd /home/lechi/Desktop/充电器/arduino
arduino-cli compile -b esp32:esp32:pico32 --output-dir ./charger_dual_rs485/ charger_dual_rs485
```

**参数说明：**
- `-b esp32:esp32:pico32`：目标板为 ESP32 Pico Kit
- `--output-dir`：指定输出目录，直接编译到工程文件夹

**注意：** 编译产物默认以 Sketch 主文件名加 `.ino.bin` 后缀，需手动重命名：

```bash
mv ./charger_dual_rs485/charger_dual_rs485.ino.bin ./charger_dual_rs485/charger_dual_rs485.bin
```

## 输出

编译产物（位于 `./charger_dual_rs485/`）：
- `charger_dual_rs485.bin` — 固件（重命名后）
- `charger_dual_rs485.ino.bin` — 固件（原始名称）
- `charger_dual_rs485.ino.bootloader.bin` — 引导程序
- `charger_dual_rs485.ino.partitions.bin` — 分区表
- `charger_dual_rs485.ino.merged.bin` — 合并固件（含 bootloader 和分区）

## 烧录

```bash
arduino-cli upload -b esp32:esp32:pico32 -p /dev/ttyUSB0 charger_dual_rs485
```

将 `/dev/ttyUSB0` 替换为实际串口设备。

## 工程结构

```
arduino/
└── charger_dual_rs485/
    ├── charger_dual_rs485.ino    # 入口: setup() / loop()
    ├── charger_dual_rs485.ino.bin  # 编译产物
    ├── app_config.h              # 引脚、UART、业务参数
    ├── rs485.h / rs485.cpp       # 双路 RS485 封装
    ├── modbus.h / modbus.cpp     # Modbus 通信
    ├── charger_fsm.h / .cpp      # 充电状态机
    ├── io_ctrl.h / io_ctrl.cpp   # LED / 蜂鸣器 / 按键
    └── ui_oled.h / ui_oled.cpp   # OLED 显示
```
